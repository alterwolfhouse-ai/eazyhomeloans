# Eazy Home Loans

Client discussion workspace for the Alter Labs project currently referred to as
Eazy Home Loans.

This is a discovery pass, not an implementation pass. The purpose is to clarify
the client's business model, service scope, target customers, trust signals, and
digital product requirements before design or development begins.

## Current Artifacts

- `docs/client-discussion-brief.md` - founder-level understanding and meeting direction.
- `docs/discovery-questionnaire.md` - questions to ask the client in the first discussion.
- `docs/service-and-product-direction.md` - potential loan services, website sections, and conversion flows.
- `docs/requirements-map.md` - design-to-backend requirements map based on the Figma export.
- `backend/` - first backend foundation for lead capture, calculators, and admin CRM.
